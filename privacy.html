智填 FormPilot 隐私政策

核心承诺：表单内容与你的档案，永不经过我们的服务器

最后更新：2026-09-15 · 适用于浏览器扩展「智填 FormPilot」（Chrome / Edge / Firefox / 360）

概述

智填 FormPilot 是一款辅助填写网页表单的浏览器扩展。我们的核心数据原则：

  • 本地优先：你的档案与设置只保存在本机浏览器，我们无法访问；
  • 最小发送：只有你主动触发智能填报时，必要信息才会发给当前配置的大模型服务商（默认为内置的智谱免费模型，可自行更换为自己的服务商与接口地址）；
  • 匿名统计：可选的心跳统计只含 5 个无身份字段，不含任何用户内容。

不收集：浏览历史、网页内容（表单之外）、个人身份信息、精确位置、cookie / 追踪器。

数据流说明

  • 智能填报链路：页面字段 + 材料 → 扩展后台 → 你配置的模型 API（OpenAI 兼容协议）→ 回到扩展。开发者不设中转服务器，无法看到这些内容。
  • 大模型服务商对请求内容的处理遵循其各自的隐私条款，请选择可信服务商并设置消费限额。
  • OCR 功能（扫描件 PDF、上传的图片、粘贴/框选的截图）会把图片发给你在设置中配置的视觉模型，性质同上；未配置视觉模型时不会发送任何图片。

权限用途

  • storage：本地保存设置与档案
  • scripting、内容脚本：注入操作面板、读取与回填表单
  • activeTab、webNavigation：确定扫描与回填的目标标签页；「截取页面」仅截取当前标签页的可见区域
  • contextMenus：右键菜单入口
  • alarms：每周一次的匿名活跃心跳

匿名统计（可选、最小化）

  • 安装及每周活跃时，可能向开发者的统计服务发送一条匿名心跳，内容仅限：事件类型、插件版本号、浏览器类型、免费/专业版状态、当月填报次数。
  • 不含任何页面内容、表单字段、文件、网址或个人身份信息。
  • 卸载插件即停止；也可通过网络层屏蔽统计域名。

数据删除

卸载扩展即删除全部本地数据（档案、设置、配额记录）。云端统计不含任何可关联到个人的信息。

建议使用官方或可信的大模型服务商，并为 API Key 设置消费限额。Key 仅保存在本机，请求时直接发往你配置的接口地址；「配置备份」导出的 JSON 默认不含 API Key，只有显式勾选才会导出完整配置。
