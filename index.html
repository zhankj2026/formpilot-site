常见问题

我的数据安全吗？

「我的档案」与设置只保存在你本机浏览器。只有你点击智能填报时，必要信息才会发往当前配置的大模型服务商（默认为内置的智谱免费模型），我们不设中转服务器。详见隐私政策。

需要自己准备大模型吗？

不需要。插件内置了智谱免费模型（glm-4-flash + 视觉模型 glm-4v-flash），安装即可直接使用。如果你更愿意用自己的模型，插件支持所有 OpenAI 兼容接口（DeepSeek / 通义 / Kimi / OpenAI / Ollama 本机模型等），在设置里填地址和 Key 即可，自带 Key 使用不限量。

扫描版 PDF、图片、截图能用吗？

能。插件会自动检测扫描件，逐页转成图片发给视觉模型（如免费的 glm-4v-flash）识别文字；上传的图片、Ctrl+V 粘贴的截图、用「📷 截取页面」框选的表单区域走同一条链路，识别结果直接进入填报材料。

免费额度用完了怎么办？

等下月刷新，或升级专业版不限次数。在设置里填入自己的模型 API Key 后使用也不限量（模型费用由你向服务商支付）。

插件如何升级？

从商店安装的会自动静默更新，无需操作；其他渠道安装的版本，插件会自动检测新版本——有更新时工具栏图标出现红色「新」角标并在面板顶部提示，点「查看更新」即可获取最新版。也可以随时在「设置 → 授权 → 检查更新」手动检查。

支持哪些浏览器？

Chrome、Edge、360 极速、Brave 等 Chromium 内核浏览器，以及 Firefox；Safari 可通过源码转换使用。
